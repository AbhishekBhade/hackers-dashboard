# Hacker Dashboard

## Overview
The Hacker Dashboard is a fully functional productivity dashboard designed with a hacker-themed aesthetic. It features a dark UI with neon-glow effects and a matrix-style animated background, providing an immersive experience for users looking to manage their tasks efficiently.

## Features
- **Task Management System**: 
  - Add new tasks
  - Mark tasks as complete or incomplete
  - Delete individual tasks
  - Clear all tasks
  - Show due dates for tasks
  - Live task count display
  - Animated progress bar to visualize task completion

- **Responsive Design**: The dashboard is designed to be mobile-responsive, ensuring usability across various devices.

- **Custom Fonts**: Utilizes the "Share Tech Mono" font from Google Fonts for a consistent hacker-style appearance.

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Open `index.html` in your web browser to view the dashboard.

## Usage Guidelines
- Use the input field to add new tasks and click the "Add Task" button.
- Click on tasks to mark them as complete or incomplete.
- Use the delete button to remove individual tasks or the "Clear All" button to remove all tasks.
- Set due dates for tasks to keep track of deadlines.
